## 작성 가이드 (template만으로 분량이 가벼워질 위험 방지)

각 섹션 최소 분량 기준:

| 섹션 | 최소 깊이 | 자주 빠지는 것 |
|---|---|---|
| 배경 | 2~5줄 + 결정 필요했던 trigger 인용 | 운영자 한 줄 발언만 박고 끝 |
| 결정 | 1~3줄 + 변경 전/후 대비 표 | "X로 바꿈"만 — 변경 범위 모호 |
| 이유 | 2~6줄 + 다른 옵션 reject 근거 | 채택 옵션 장점만 나열, 다른 옵션 부재 |
| 트레이드오프 | 표 또는 2~5줄 + 포기한 측면 명시 | 빈 채로 두기 |
| 영향 | 변경 대상 파일·섹션 리스트 또는 §갱신 목록 | "spec 전체 갱신" 같은 모호 표기 |
| 후속 추적 | 재검토 trigger 조건(메트릭·시간·이벤트) | "필요 시 재검토" 같은 빈 약속 |
